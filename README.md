# astrbot_plugin_chem_structure · 化学结构简式

> 仓库：[NekoHome-Studio/astrbot_plugin_neko-chem](https://github.com/NekoHome-Studio/astrbot_plugin_neko-chem) · 许可：MIT

一个 AstrBot 插件：把**中文名 / 俗名 / SMILES / 结构简式 / 分子式**画成图，
并给出分子式、相对分子质量、元素质量分数。

支持两种画法：

| 画法 | 长什么样 | 适用 | 依赖 |
| --- | --- | --- | --- |
| **结构简式**（连写式） | `CH₃CH₂OH` | 链状有机物、苯系物 | 无（纯 Python 排版） |
| **键线式**（骨架式） | 六边形、锯齿链，碳在顶点上不写出来 | 环烷烃、苯、萘、杂环、糖环…… | 无（**自研引擎**） |

再加上可选的 RDKit 结构式绘图（装了就用，没装也不影响）。

```
/结构 乙醇          →  CH₃CH₂OH 图片
/结构 环己烷        →  正六边形键线式
/化学 键线式 萘     →  两个稠合六边形
```

---

## 1. 安装

把整个 `astrbot_plugin_chem_structure` 目录放进 AstrBot 的插件目录：

```
AstrBot/data/plugins/astrbot_plugin_chem_structure/
```

然后在 WebUI 的「插件管理」里重载，或发 `/化学 状态` 确认已加载。

第三方依赖只有 **Pillow**（画图用）：

```bash
pip install pillow
```

AstrBot 通常已经装了 Pillow。没装的话插件会自动降级为纯文本输出，不会崩。

### RDKit 是完全可选的

```bash
pip install rdkit      # 可选
```

* 装了：`/化学 结构式` 优先用 RDKit 绘制，画质与通用性最好；
* 没装：**自动改用插件自带的纯 Python 键线式引擎**，功能不受影响；
* 所以不需要为了这个插件去折腾 RDKit 或换 Python 版本。

## 2. 指令

| 指令 | 作用 |
| --- | --- |
| `/化学 结构 <物质>` | 画图 + 文字信息；环状物质自动改画键线式 |
| `/化学 简式 <物质>` | 只用文字给出结构简式 |
| `/化学 分子式 <物质>` | 分子式、相对分子质量、元素质量分数 |
| `/化学 键线式 <物质>` | 用内置引擎画键线式（不依赖 RDKit） |
| `/化学 结构式 <物质>` | 画结构式：优先 RDKit，否则用内置引擎 |
| `/化学 列表 [类别/关键词]` | 浏览内置物质词表 |
| `/化学 状态` | 环境自检：字体、RDKit、缓存、调用统计 |
| `/化学 帮助` | 使用说明 |
| `/结构 <物质>` | 顶层快捷方式，等价于 `/化学 结构` |

指令组 `化学` 还有别名 `chem`，所以 `/chem 结构 乙醇` 同样有效。
直接发 `/化学` 不带子指令时，AstrBot 会渲染出完整的指令树。

### 输入示例

| 类型 | 示例 |
| --- | --- |
| 中文名 / 俗名 | `乙醇`、`甘油`、`草酸`、`TNT`、`胆矾`、`葡萄糖`、`环己烷`、`萘` |
| SMILES | `CCO`、`c1ccccc1`、`CC(=O)O`、`C1CCCCC1` |
| 结构简式 | `CH3CH2OH`、`CH2=CH2`、`CH3(CH2)4CH3`、`CuSO4·5H2O`、`CH₃CH₂OH` |
| 分子式 | `C2H6O`、`C6H6`、`NaCl`、`KMnO4` |

内置词表共 **134 条**物质，覆盖 26 个类别。

| skeletal | `enabled` | true | 启用自研键线式引擎 |

| skeletal | `transparent` | false | 键线式透明背景 |
| skeletal | `show_hydrogens` | true | 杂原子上写氢（`OH`、`NH₂`） |

| skeletal | `use_rdkit` | true | 装了 RDKit 时 `/化学 结构式` 是否优先用 RDKit |

## 5. 它是怎么画的

### 5.1 结构简式（连写式）

`chem/condense.py` 按中学教材约定，从分子图生成简式：

1. **省略键线**：C–C、C–杂原子单键都不写 `-`；
2. **只保留碳碳重键**：`C=C` 写 `=`、`C≡C` 写 `≡`；`C=O`、`C≡N`
   直接连写（`CO`、`CN`）；
3. **主链 + 支链**：支链写在分支点之后、主链延续之前，相同支链合并下标
   —— `CH3CH(CH3)COOH`；
4. **官能团位置**：羧酸/酯从酰基一侧写起，得到 `CH3COOH`、`HCOOCH3`；
5. **醛基的氢**：`CH3CHO`；若该碳是书写起点则提到最前（`HCHO`、`HCOOH`）；
6. **苯环**：按苯基展开，`C6H5-`、`C6H4-`。

生成结果会**回算分子式与原分子比对**，不一致就拒绝输出。

### 5.2 键线式（自研引擎）

分两步：`chem/layout.py` 算二维坐标，`chem/render_skeletal.py` 画图。

**坐标生成**（`layout.py`）：

1. **找环（SSSR）**：对每根键，暂时断开它求两端点最短路，得到包含该键的
   最小环；再用 GF(2) 上的线性无关性，从小到大贪心挑出
   `环数 = 键数 − 原子数 + 组分数` 个环。苯 → 1 个六元环，萘 → 2 个六元环
   （而不是一个十元环）。
2. **摆环**：第一个环摆成正多边形；其余环按三种连接方式拼接 —— 共享一条
   边（稠环）、共享一个原子（螺环）、环上某原子已与骨架成键（联苯、被链
   隔开的两个环）。摆环与摆链交替进行，直到没有新进展。
3. **摆链**：环上原子朝环外伸展；链上原子相对上一根键交替转 ±60°，
   连续转下去就是教材里的锯齿形（相邻键夹角 60°，即键角 120°）。
   每个待扩展原子里单独选出"延续主链"的那一个，其余取代基挂在旁边并
   自动避开已有原子。
4. **松弛**：键长弹簧 + 非键斥力迭代，把所有键长拉回 1.0。
   首次失败时用不同的取代基张角重试几次（确定性偏移，不用随机数），
   取最好的一次。

**绘制**（`render_skeletal.py`）：

* 碳在顶点上不写出来，杂原子标元素符号并带上氢（`OH`、`NH₂`）与电荷；
* 双键画两条平行线：环内的第二条画在环内侧并稍短，环外的（羰基等）两条等长；
  三键画三条线；
* 芳香环用**凯库勒式**（交替双键）。凯库勒化是在可参与双键的芳香原子上
  求最大匹配，每次先配"可选伙伴最少"的原子，这样吡咯才能正确配出
  `C0=C4`、`C1=C2` 两根双键；
* 杂原子按 CPK 风格着色（O 红、N 蓝、S 黄、卤素绿/紫）；
* 标签带描边，压住底下的键线，不需要手工截断键。

### 5.3 结构简式图片排版

`chem/render_png.py` 用 Pillow 自己排版：**下标**按"更小字号 + 按字体
metrics 反推的基线偏移"绘制，因此不依赖字体是否含 Unicode 下标字形
（`₃` 在很多中文字体里是缺字形的方框）。字体在 Windows / macOS / Linux
常见路径里依次探测（`chem/fonts.py`），找不到就退回 Pillow 内置字体并
在 `/化学 状态` 里说明。

## 6. 已知限制（重要）

### 6.1 结构简式给不出来的情况

* **环状结构**：环己烷、环己烯、环氧乙烷等。连写式简式无法无歧义表达成环，
  插件会自动改画键线式（`prefer_for_cyclic` 控制）。
* **杂环 / 稠环**：吡啶、呋喃、萘、蒽。同样自动改用键线式。
* **分子式无法唯一确定结构**：`C2H6O` 既可能是乙醇也可能是甲醚，会列出
  词表里的全部候选，不会替你猜。
* **只给简式或分子式时没有键连信息**，画不出键线式；想要图请给中文名或
  SMILES。
* **高分子**：淀粉、纤维素只有 `(C6H10O5)n`，聚合度不定，相对分子质量无法给出。
* **写法风格差异**：少数分子有多种同样正确的简式。插件按统一评分规则
  （括号更少 → 官能团在主链末端 → 碳链更长）挑一种，可能与某本教辅略有
  出入，例如丙烯输出 `CH2=CHCH3`，教材可能写 `CH3CH=CH2`。两者都对；
  常用物质的教材写法已在内置词表里固定。

### 6.2 键线式排版的边界

这是一套"教学级"排版，不是 RDKit 那种通用坐标生成器。

* **桥环**（如降冰片烷）在平面上根本无法用规整多边形表示（两个环共享
  连续多条边时几何上无解）。插件会检测到并**拒绝出图**而不是画一张错的，
  提示改用 RDKit。
* **超大柔性分子**：原子数超过 36 时不启用多起点重试；像三硬脂酸甘油酯
  （60 个重原子）这类会因原子挤压而拒绝出图。
* **立体化学**：不表达手性中心的楔形/虚线，只画二维连接关系。
* 螺环化合物两个环上相邻原子距离会到 1.0 个键长，这是正多边形几何的
  必然结果，实际教材画法也是如此。

被拒绝时命令会明确说明原因，不会静默给一张错图。绝大多数中学常见物质
（含苯系物、单环/稠环芳烃、杂环、糖环、柠檬酸、咖啡因这类）都能正常绘制。

### 6.3 输入解析

* SMILES 覆盖常用子集：有机子集、芳香小写、支链、成环、方括号原子、
  电荷、同位素、手性标记与 `.` 断开；不做立体化学解释，原子映射编号忽略。
* 单次输入上限 200 字符（WebUI），参与简式自动推导的重原子上限 60 个。
* 离子化合物（NaCl、CuSO4、Na2CO3 等）由互不相连的组分构成，键线式
  不适用；`/化学 键线式` 会明确说明这一点，而不是画一张没有意义的图。
* **纯 ASCII 文本里的电荷有歧义**：`render_ascii` 用 `-`/`+` 表示电荷，
  而 `-` 同时是键符号。电荷在**末尾**时没问题（`CH3COO-`、`NH4+`），
  但像硝酸根这种电荷夹在中间的写法会渲染成 `O-NO2`，再解析回去会被当成
  键而丢掉电荷。图片与 Unicode 形式用上标字符，不受影响；教材写法的离子
  电荷本来就在末尾，所以实际影响很小。

## 7. 目录结构

```
astrbot_plugin_chem_structure/
├── main.py                  AstrBot 插件入口：指令、事件钩子、Web API
├── service.py               配置解析、出图、图片缓存
├── metadata.yaml            插件元数据
├── _conf_schema.json        WebUI 配置 Schema
├── requirements.txt         依赖声明
├── chem/                    化学核心库（不依赖 AstrBot，可独立测试）
│   ├── elements.py          元素表与相对原子质量
│   ├── model.py             简式 AST、分子式、摩尔质量、文本/HTML 渲染
│   ├── text_formula.py      简式/结构式文本解析器
│   ├── smiles.py            SMILES 解析器（含隐式氢推断）
│   ├── condense.py          分子图 → 结构简式
│   ├── names.py             中文名/俗名词表（134 条）
│   ├── resolve.py           四类输入的统一识别入口
│   ├── fonts.py             跨平台字体探测与文字测量
│   ├── layout.py            键线式二维坐标生成（SSSR / 摆环 / 锯齿链 / 松弛）
│   ├── render_png.py        Pillow 结构简式渲染
│   ├── render_skeletal.py   Pillow 键线式渲染
│   └── render_rdkit.py      可选的结构式渲染
├── pages/structure/         WebUI 预览页（index.html / app.js / style.css）
├── .astrbot-plugin/i18n/    Page 文案（zh-CN / en-US）
└── tests/test_chem.py       离线测试，不需要 AstrBot
```

`chem/` 与 AstrBot 完全解耦，只依赖标准库（绘图部分需要 Pillow，
结构式绘图是可选增强），可以单独拿去做别的项目。

## 9. 依赖与来源声明

* 运行期依赖：**Pillow**（`pillow>=9.0.0`）；RDKit 可选。
* 网络库：本插件**不需要联网**，不发起任何 HTTP 请求，也不使用 `requests`。
* 数据来源：内置词表中的物质名称、俗名、SMILES 与教材简式，均为公开的
  化学通识内容，参照中学教材与教材配套资料的常见写法手工整理，**没有
  复制任何第三方代码或数据文件**。
* 键线式的排版与绘制（`chem/layout.py`、`chem/render_skeletal.py`）为
  本项目原创实现，未使用 RDKit 或任何第三方化学绘图库的代码。
* 元素相对原子质量：IUPAC 2021 标准原子量（放射性元素取最长寿同位素质量数）。
* 持久化数据：图片缓存写在 AstrBot 的 `data/plugin_data/<插件名>/cache/`，
  不放插件自身目录，会根据 `cache.max_files` 与 `cache.ttl_hours` 自动清理；
  发送用的临时图片通过 `event.track_temporary_local_file()` 交给 AstrBot
  在发送完成后删除。
